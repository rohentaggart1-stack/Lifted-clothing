# LIFTED — Updated GitHub Pages Website

This version fixes the broken-image problem by keeping every product image inside the repository and using simple local paths.

## Upload structure

Keep this exact structure in the root of your GitHub repository:

- index.html
- styles.css
- script.js
- logo.svg
- images/
  - hoodie.png
  - tee.png
  - shorts.png
  - beanie.png
  - denim.png
  - pants.png

Upload the **whole `images` folder**. Do not upload only the HTML/CSS files.

The site is centered, black, responsive, and streetwear-focused.
